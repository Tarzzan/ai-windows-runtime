# Vision Produit

## Vision
Create the most reliable Linux-native runtime for Windows applications by combining systems engineering with continuous AI-assisted compatibility learning.

## Product principles
- Native first: no VM requirement.
- Evidence driven: every compatibility claim is trace-backed.
- Incremental reliability: prefer deterministic progress over broad unsupported promises.
- Human-reviewed automation: AI proposes, engineers validate, CI enforces.

## Initial target profile
- Ubuntu desktop environments.
- Installer-heavy enterprise applications.
- Complex API surfaces: Win32 + COM + selected WinRT interaction points.

## Success criteria (phase-level)
- Repeatable installer execution pipeline.
- Stable diagnostics for failure modes.
- Reduction in unresolved API gaps across test corpus.
- Reproducible engineering loop from failure trace to patch candidate.
