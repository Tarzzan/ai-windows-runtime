# Roadmap 30/60/90

## Day 0-30 (MVP Foundation)
- Define runtime evidence schemas (trace, gap, proposal).
- Build minimal trace parser + gap detector + patch planner.
- Create compatibility corpus with 5 installer scenarios.
- Add CI for lint/test/artifact checks.
- Establish reproducible Ubuntu bootstrap script.

Exit criteria:
- End-to-end trace -> gap -> plan flow works on sample corpus.
- All baseline tests pass in CI.

## Day 31-60 (Runtime Diagnostics & Targeted Compatibility)
- Implement richer trace categories (loader, COM, registry, network).
- Add ranking model for blocker severity.
- Integrate first runtime telemetry adapters.
- Start targeted shims for top 10 blockers from corpus.
- Add regression dashboard report generation.

Exit criteria:
- 30% reduction of critical unresolved blockers on corpus.
- Deterministic reproduction package for each failure.

## Day 61-90 (Stabilization & First Real-world Pilot)
- Expand corpus to 15 scenarios including Office-like bootstrap installers.
- Harden patch acceptance workflow (quality gates + rollback policy).
- Document operational runbook for contributors.
- Publish alpha release with known compatibility matrix.

Exit criteria:
- Pilot scenario set runs with documented success/failure reasons.
- Alpha release artifacts reproducible from clean Ubuntu host.
